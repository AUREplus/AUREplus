# AUREplus

Web de AUREplus, agencia de automatización especializada en joyerías. Creamos asistentes virtuales que funcionan como una recepcionista 24/7 por WhatsApp, Instagram y web.

## Contenido

- `index.html` — la página completa (HTML, CSS y JavaScript en un solo archivo, sin dependencias de build).
- `img/` — imágenes y vídeos de la portada.
- `serve.js` — servidor local mínimo para previsualizar la web durante el desarrollo:
  ```
  node serve.js
  ```
  y abrir `http://localhost:8080/`.

## Formulario de contacto

El formulario de "Prueba gratuita" envía los datos mediante [FormSubmit](https://formsubmit.co). El identificador usado en `index.html` (`DEMO_FORM_ID`) está activado para el dominio con el que se probó originalmente; si cambias de dominio, FormSubmit puede pedir una reactivación y entregar un identificador nuevo.
